# Проекты — тестовое задание

Учебная страница «Проекты», созданная с помощью AI для выполнения тестового задания.

## Рабочая версия

https://proekty-sergey-test.goldfuture25.chatgpt.site

## Возможности

- список тестовых проектов;
- поиск проектов по названию;
- создание нового проекта через форму;
- проверка обязательных полей;
- сохранение созданных проектов в localStorage;
- сохранение данных после обновления страницы;
- адаптивная версия для мобильных устройств.

- сформулировал требования к странице и создавал её с помощью AI;
- проверял работу готовой страницы вручную;

## Проверки

Проверил:

- поиск по части названия;
- поиск без учёта регистра;
- поиск с пробелами в начале и конце запроса;
- состояние, когда ничего не найдено;
- создание проекта;
- обязательность названия и описания;
- ввод только пробелов;
- обрезку лишних пробелов;
- кнопку «Отмена»;
- сохранение проекта после обновления страницы;
- длинные название и описание;
- отображение на мобильной ширине 393 px;
- сохранение проекта на мобильном устройстве.

## Найденная и исправленная ошибка

При вводе только пробелов в поля формы проект не создавался, но пользователь не получал понятного сообщения о причине.

После исправления значения из одних пробелов считаются пустыми, а под соответствующими полями отображаются сообщения об ошибке.
